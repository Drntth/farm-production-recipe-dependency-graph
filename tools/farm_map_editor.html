Map Editor

1. Calibrate the tile grid

How to
Ruler: two rows of fields (town / lake: path tiles or other 1x1 items) in an L shape from one corner tile, one row along ↘ and one along ↙. Click the three points (zoom in for precision); a left drag pans. Drag a placed point to move it.
  1. A: top corner of the corner field
  2. B: right corner of the last field of the ↘ row
  3. C: left corner of the last field of the ↙ row
Not calibrated.

2. Buildings

How to
Pick an id (or type a new one), then drag over every tile the building blocks (e.g. the truck with its order board). Dragging again moves it. Click a row to select it. Farm: barn and silo are optional; without a position the planner places them. Town: tick movable for buildings the planner may rearrange (the service buildings).

    3. Reference overlay (optional)

    How to
    Overlay another image (e.g. the wiki plot map) to trace plot borders that are gone from the screenshot. Load it, then click 3 points spread far apart, each first on the overlay (r) and then on the same spot of the map (m): r1, m1, r2, m2, r3, m3. Zoom to the part of the map the overlay shows, then load it: it starts fitted into the visible area. After each pair it snaps closer (1 pair: moved, 2 pairs: scaled and rotated, 3 pairs: fully fitted), so the later points need less zoom. Drag a placed point to move it; where an r and an m point overlap, the drag takes the m point (the overlay follows), Shift + drag the r point. Reset alignment fits the overlay into the visible area again. A left drag on empty space pans. The overlay is not saved in the JSON.
    No overlay.

    4. Plots (expansions)

    How to
    Farm plots (wiki: Expansion/Farm). Add a plot, then drag rectangles to cover its tiles; touching rectangles merge into one shape. Alt + drag erases tiles of the selected plot. Draw the starting land as section base.

      5. Zones

      How to
      Buildable (green): the farm sections; the layout stays inside them. Blocked (red): water, road, forest, paved strips, … never used. Design (violet): existing decorations; no block is placed there, but paths may cross it. Add a zone, then drag rectangles; touching rectangles merge. Alt + drag erases tiles of the selected zone.

        6. Export

        Relative to config/<area>_map.json; save the screenshot next to it, e.g. config/farm_background.png.
        Cropping keeps every plot, buildable zone and building plus the margin; blocked and design zones are cut at the new edge. The editor switches to the cropped map too.
        PNG and pieces use the visible layers. The ZIP holds one PNG per plot, index.json (crop and tile bounds) and the map JSON.
